# 手办效果图生图归档

本文件归档 Image-to-3D 管线第 ② 步（先生图）的完整可复现参数。

## 输入参考图

| # | 素材 | 来源 | 角色 |
|---|---|---|---|
| 图1 | semi-chibi 角色正面图 | `Neko3000/deepseek-whalechan` | 提供脸、发型、整体比例 |
| 图2 | 角色设计稿 | `Mizimo/whale-girl-visual-language-v4` | 提供女仆装层次与细节 |

参考图**不随本仓库分发**，请按 `reference/SOURCES.md` 的地址与 SHA-256 自行获取。

## 生成参数

- 工具：MiniMax image generation（Matrix 连接器，`matrix__generate_image`）
- `aspect_ratio`: `3:4`
- `n`: `2`
- `output_file`: `whale-chan-figurine`
- `reference_images` 传入格式**必须**为对象数组：

  ```json
  [
    {"url": "https://.../fig1.png", "mime_type": "image/png"},
    {"url": "https://.../fig2.png", "mime_type": "image/png"}
  ]
  ```

  ⚠️ 传裸字符串数组会导致调用以 `latency_ms: 0` 静默失败。

## Prompt（原文）

```text
按图1（角色正面图）和图2（角色设计稿）的参考，生成一个完整的 Q 版 semi-chibi 3D 手办产品渲染图。

图1提供角色的脸、发型与整体比例，图2提供女仆装的层次与细节。请准确保留：
- 2.8 头身的 Q 版比例，头大身小
- 深蓝到天蓝渐变的长发、两侧垂落的发束、头顶一撮呆毛
- 头顶一圈白色珍珠发饰，额前天蓝色刘海
- 头两侧深蓝色的鲸鱼鳍耳，向外上方伸展
- 蓝色渐变大眼、淡粉腮红、小巧的嘴
- 深蓝女仆装：白色蕾丝领口 + 珍珠串 + 深蓝领结，白色围裙（围裙正面有小鲸鱼刺绣图案），裙摆有金色刺绣线和白色荷叶边
- 白色过膝袜 + 深蓝色玛丽珍鞋
- 身后的鲸鱼尾巴

构图与质感：干净米白色纯背景，不要底座、文字、水印或任何额外道具；从呆毛尖到鞋底全身完整入镜，四周留白不要裁切；正面略带 15 度侧角，同时看清脸和身体厚度；双臂稍微离开躯干；鲸鱼尾巴从腰后伸出并完整可见，不被裙摆或手臂遮挡；树脂手办的柔和材质、轻微次表面散射，棚拍柔光，不要过曝。
不要出现：底座、文字、水印、多个人物、裁切、缺失的尾巴、写实人类身体比例
```
