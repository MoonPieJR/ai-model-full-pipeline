## 4. 几何实现规则（踩坑固化，改动前必读）

这些不是风格偏好，是**踩过之后定下的硬约束**，违反会直接产生可见缺陷。

### 4.1 顶点构建在世界坐标，物体 transform 保持 identity

所有 `add_mesh` 的顶点都是世界坐标，物体本身不做位移/缩放。
理由见 §1 的渐变说明 —— 这是"发色全局渐变"成立的前提。

### 4.2 `cyl_patch` 的背面壳半径必须是 `r - thickness`

背面壳与正面壳半径相同 → 两层壳永久重合 → **z-fighting**。
表现为布片上一道道横向条纹（不是摩尔纹，是渲染器在两层重合面之间随机命中）。

### 4.3 贴合面片的半径必须避开被贴合物的波形峰

裙身是 `lathe_wave`，半径被**乘性**调制：`r_actual = r · (1 ± amp)`。
围裙半径必须 ≥ `r_peak + 净空(≈0.018)`，否则裙面在若干 z 区间穿透围裙，
正面看同样是横向条纹。围裙的 8 个站位半径就是按这个规则反推的。

### 4.4 站位之间必须平滑，不能折线连接

稀疏站位直接连线 → 每个站位留一道折角 → 正面看是横向亮带。
`cyl_patch(subdiv=4)` 用 Catmull-Rom 在 z 与 r 两维同时插值后加密。

### 4.5 `lathe` 的顶点是「圈优先」排列

第 i 圈占 `verts[i*n:(i+1)*n]`，n = 轮廓点数；封口面连的是轮廓上的 n 个点，
**不是**周向的 segs 个。搞错会导致封口面索引越界或破面。

### 4.6 头发开口用角度判据，不用平面切

`abs(atan2(x, -y)) < 44°` 判正前方。平面切（`y < -0.13`）会让侧脸整块裸露，
侧视图变成一颗光秃秃的脸蛋；角度开口则保留两鬓头发，符合参考图。

### 4.7 侧发束必须落在中平面之后（y ≈ +0.09）

落在 y≈0 时，纯侧视图（相机在 +X）会看成一束头发垂在身体**正前方**。

### 4.8 眼睛的 Y 向深度不能压太扁

半深 0.050 时侧视图完全看不到眼睛弧线，脸是一整块无五官的浅色。0.062 可接受。

### 4.9 bpy 退出必须走 `quit_blender()` + `os._exit(code)`

否则进程析构时段错误，产物虽已落盘但退出码非零，会打断自动化流水线。
